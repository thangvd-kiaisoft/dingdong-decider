# Ding Dong Decider – policy pages

Static pages served with GitHub Pages:

- `index.html` – privacy policy (Vietnamese, Japanese, English)
- `support.html` – support / FAQ and contact

The language follows the browser, or the URL hash: `#vi`, `#ja`, `#en`.
Source of truth: `docs/privacy_site/` in the app project. Keep the text in
sync with `docs/release/privacy_policy.md` and bump the "last updated" date
when it changes.
